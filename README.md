# Unity-Robot-Simulation
Advanced Unity Robot Simulation

## Overview
 - Blackbox of sorts for data obtained from testing.
 - Simulate competition/underwater environment to test submarine without having to actually put it in the water every time.
 - Second version, being updated for 2025.

## Goals
 - Using a Computational Fluid Dynamics software (Ansys Fluent) and visualize/use its data in the simulation for accurate-to-life/water physics testing
 - Send I/O signals to the sub

## Getting Started

 - Install UnityHub from https://docs.unity3d.com/hub/manual/InstallHub.html
 - Clone the Advanced-Unity-Robot-Simulation repository to your local machine.
 - In UnityHub, under projects click "add" --> "add from disk" and select the entire repository file.
 - A prompt will appear to download the corresponding Unity version (if it is not already installed). Click through these windows; everything is already configured.
 - The repository will appear on the project list. Click to open the simulation.
 - In the "Assets" tab under the "Project" window, navigate to the "Scenes" folder. Double click any scene to open it in the play window.
 - "RobotSim" is a full simulation of the RoboSub. "PIDSim" is a demonstrative simulation of PID controllers.
